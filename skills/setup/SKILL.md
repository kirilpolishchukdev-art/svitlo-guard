# Налаштування svitlo

svitlo стежить за графіком відключень світла користувача. За кілька хвилин до відключення агенти Claude Code доводять роботу до цілісного стану, а сесію потім можна продовжити через `claude --resume`. Твоя задача — зібрати три відповіді й зберегти їх. Говори з користувачем українською.

## Кроки

1. Завантаж інструменти одним викликом: `ToolSearch` із запитом `select:mcp__svitlo__regions,mcp__svitlo__configure,mcp__svitlo__schedule`.
2. Виклич `mcp__svitlo__regions`. Він повертає id регіонів (області й окремі оператори) та їхні черги. Якщо сервіс недоступний — скажи про це й запропонуй повторити пізніше. Нічого не вигадуй.
3. Запитай користувача (зручно через `AskUserQuestion`, якщо він є):
   - **Область.**
   - **Населений пункт.** Від нього залежить id:
     - місто Київ → `kyiv`, Київська область → `kiivska-oblast`;
     - місто Дніпро → `dnipro-dnem` або `dnipro-cek`, залежно від оператора в платіжці; інші населені пункти Дніпропетровщини → `dnipropetrovska-oblast`;
     - решта → id області.
   - **Черга й підчерга**, наприклад `3.1`. У Чернівецькій і Донецькій областях групи без підчерги: `1`…`12`.
4. Якщо користувач не знає своєї черги, допоможи її знайти. Обленерго (ДТЕК, YASNO, Львівобленерго тощо) показують чергу за адресою на своєму сайті або в чат-боті. Знайди через `WebSearch` офіційну сторінку «черга за адресою» для його області й дай посилання. Адресу користувача нікуди не передавай без його згоди.
5. Спитай, за скільки хвилин до відключення зупиняти агентів. За замовчуванням 20, допустимо від 5 до 120.
6. Виклич `mcp__svitlo__configure` з `region` (id зі списку), `queue` і `leadMinutes`. Якщо інструмент повернув «Помилка», покажи користувачу доступні варіанти з відповіді й спитай ще раз.
7. Покажи коротке зведення з відповіді: графік на сьогодні й завтра. Поясни, як працює svitlo:
   - у рядку статусу видно, коли наступне відключення;
   - за N хв до відключення агенти й субагенти отримують вказівку не починати нового, довести зміну до цілісного стану й підсумувати, де зупинилися;
   - за 2 хв інструменти блокуються, щоб робота не обірвалася посередині;
   - після відключення команда `claude --resume <id>` повертає сесію. Її показує плашка, `/svitlo sessions` або повідомлення в новій сесії в тій самій теці.
   - Команди: `/svitlo` — графік, `/svitlo pause` — пауза до кінця найближчого відключення (є ДБЖ або генератор), `/svitlo on` — увімкнути знову, `/svitlo test 19` — перевірити роботу на симуляції.

## Межі

- Графіки беруться з відкритого API svitlo.live, яке збирає дані обленерго. Під час аварійних відключень світло можуть вимкнути й поза графіком. svitlo про це попереджає, але передбачити такі відключення не може.
- Не налаштовуй нічого поза svitlo: settings, хуки й автоматичні коміти не чіпай.
