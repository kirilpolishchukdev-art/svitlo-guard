# svitlo — Claude Code і графіки відключень світла

Плагін для [Claude Code](https://claude.com/claude-code) для тих, у кого немає ДБЖ. svitlo знає графік відключень у вашому регіоні. За 20 хвилин до відключення він каже агентам завершити роботу: не починати нового, довести поточну зміну до цілісного стану й підсумувати, де вони зупинилися. Коли світло дадуть, сесію можна продовжити однією командою `claude --resume <id>`.

## Як це працює

| Коли | Що робить svitlo |
| --- | --- |
| Завжди | У рядку статусу видно наступне відключення: `💡 Світло (3.1): відключення о 14:00, через 1 год 20 хв` |
| ≤ 90 хв до відключення | До нового запиту додається примітка для агента: плануй етапами, щоб вчасно дійти до стабільної точки |
| ≤ 20 хв (налаштовується) | Головний агент і кожен субагент отримують вказівку завершувати роботу. Зверху з'являється плашка з командою відновлення і кнопкою «Копіювати» |
| ≤ 5 хв | Останнє нагадування: закінчити хід зараз |
| ≤ 2 хв і перші 5 хв відключення | Виклики інструментів блокуються, щоб робота не обірвалася посередині. `/svitlo pause` знімає блок |
| Після відключення | Нова сесія в тій самій теці показує перервану сесію і команду `claude --resume <id>` |

Попередження приходить агенту разом із результатом найближчого інструмента. Тому його отримує й довга збірка, яка перетнула межу 20 хв, і субагенти, що працюють у фоні.

## Встановлення

Потрібен Claude Code **2.1.293 або новіший**: плагін написаний на function hooks, а це API в ранньому доступі.

З GitHub, у полі вводу Claude Code:

```
/plugin install svitlo --marketplace kirilpolishchukdev-art/svitlo-guard
```

Далі `y`, щоб додати маркетплейс, і scope `user`.

Локально з теки:

```
claude plugin marketplace add C:\шлях\до\svitlo-guard
claude plugin install svitlo@svitlo-guard
```

## Налаштування

У будь-якій сесії наберіть:

```
/svitlo:setup
```

Агент спитає область, населений пункт і чергу (наприклад, `3.1`), а також за скільки хвилин зупиняти агентів. Якщо черги не знаєте, він допоможе знайти її на сайті вашого обленерго за адресою.

## Команди

| Команда | Що робить |
| --- | --- |
| `/svitlo` | Графік на сьогодні й завтра, стан і свіжість даних |
| `/svitlo pause` | Пауза до кінця найближчого відключення: немає попереджень і блоку (є ДБЖ чи генератор) |
| `/svitlo on` | Зняти паузу |
| `/svitlo test [хв]` | Симуляція відключення через N хв лише в цій сесії, щоб перевірити роботу |
| `/svitlo test off` | Вимкнути симуляцію |
| `/svitlo sessions` | Сесії, які, схоже, перервало відключення, з командами `claude --resume` |
| `/svitlo refresh` | Оновити графік зараз |
| `/svitlo reset` | Забути регіон і чергу |

Агент також може сам подивитися графік через інструмент `mcp__svitlo__schedule`.

## Звідки дані

Графіки беруться з відкритого API [svitlo.live](https://github.com/chaichuk/svitlo_live). Воно збирає дані ДТЕК, YASNO та обленерго (парсер — [yaroslav2901](https://github.com/yaroslav2901)). Покриті всі області, де графіки публікують, а Київ і Дніпро розділені за операторами. Щоб не навантажувати безкоштовний сервер, svitlo запитує його лише поки відкрита сесія Claude Code. Раз на 15 хвилин — тільки коли відключення ближче ніж за 3 години, інакше раз на годину. Усі сесії на машині ділять один кеш. Якщо svitlo вам корисний, підтримайте автора API: посилання на банку є в його README.

## Обмеження

- **Аварійні відключення** (ГАВ) відбуваються поза графіком. svitlo показує, що вони оголошені (`⚠ діють аварійні відключення`), але передбачити їх не може.
- Графік може змінитися протягом дня. svitlo підхоплює зміни із затримкою до 15 хвилин, коли відключення близько, і до години, коли до нього далеко.
- Інструмент, що вже виконується, svitlo не перериває: попередження прийде, щойно він завершиться.
- Без інтернету svitlo працює з останнім збереженим графіком і пише в статусі, звідки дані.
- Самостійно svitlo нічого не комітить і не пушить, а агентам прямо каже цього не робити без дозволу.

## Розробка

```
claude plugin validate .
claude plugin test .
SVITLO_SIMULATE_MIN=19 claude --plugin-dir .   # сесія із симульованим відключенням через 19 хв
```

- `hooks/schedule.ts` — розбір графіків, київський час (з переходом на літній і зимовий час), фази.
- `hooks/texts.ts` — тексти для агента й користувача.
- `hooks/register.tsx` — хуки: таймер, `tool.call`, `prompt.submit`, команда `/svitlo`, інструменти, плашка.
- `skills/setup/SKILL.md` — розмова з налаштування.
